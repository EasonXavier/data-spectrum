# DataSpectrum · 数据棱镜

面向《三角洲行动》公开玩家战绩的纯静态网页工具。当前功能是“KD 鉴定器”：根据总场次、总击杀、总撤离率，以及普通、机密、绝密三条队列的一位小数 KD，估算玩家可能的绝密场次区间。

当前版本：`v0.3.1`

## 在线访问

<https://easonx.me/data-spectrum/>

## 架构

站点源码全部位于 `site/`，仅使用 HTML、CSS、JavaScript 和本地 WOFF2 字体：

- 不需要 Node.js 或服务端运行时
- 不需要构建命令
- 所有计算均在浏览器本地完成
- `.github/workflows/pages.yml` 直接把 `site/` 发布到 GitHub Pages

## 本地预览

可以直接打开 `site/index.html`，或使用任意静态文件服务器预览。

## 计算说明

游戏 KD 按一位小数显示并四舍五入，真实值在 `0–0.1` 时统一显示为 `0.1`。工具会把显示值还原成可能区间后计算上下界；公开数据不能约束上界时会明确标注。截图上传入口目前仅作界面预留。
